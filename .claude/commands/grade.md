description: 제출한 SQL 채점 (예: /grade P001)
---

`sql-lab` 스킬의 **B. 채점** 절차를 따라 채점한다.

대상: $ARGUMENTS
(비어 있으면 `attempts/` 에서 가장 최근에 수정된 제출 파일을 대상으로 한다)

제출 파일은 `attempts/PNNN/tN.sql` — 문제별 폴더 안, N 은 그 폴더의 최대값.

순서를 지킬 것:
1. 오라클 문법 위반 여부 점검
2. `./bin/ocheck` 로 결과셋 검증
3. `./bin/oplan` 으로 제출·모범답안 각각 2회 실행, 두 번째 값으로 Buffers 비교
4. 실측치를 근거로 피드백. 틀렸으면 고칠 지점만 알려주고 정답은 바로 공개하지 않는다
5. 채점 내용을 **`attempts/PNNN/tN-grade.md` 파일로 남길 것** (판정·실측표·ocheck 출력·고칠 점·다음 단계).
   모범답안 SQL 은 이 파일에도 쓰지 않는다. 이전 시도의 채점 파일은 지우지 않는다
6. `progress.md` 에 결과 한 줄 추가 (채점 파일 링크 포함)
